### Project Description

This project is an interactive to-do list built with HTML, CSS and JavaScript. The goal of the task was to apply core JavaScript concepts in a practical way: DOM manipulation, dynamic element creation (`createElement`, `appendChild`), event listeners, and input validation. The app allows users to add tasks by clicking a button or pressing Enter, delete individual tasks with a dedicated button, and always shows an accurate counter of the current number of tasks. An empty-state message is displayed when the list has no items.
